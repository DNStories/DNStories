# How to use this code.

## Download APNIC data

Use the script `download-apnic-data.py` to download a local working version of the Open Resolvers dataset

## Create region and sub-region maps.

Run the notebook `Create CC m49 map.ipynb` to generate some maps that associate country codes into regions and sub-regions for analysis

## Analyze APNIC data

Run the notebook `Present changes.ipynb` to analyze the local APNIC data downloaded

## Correlate to Freedom of Press Index

Use the notebook `Index correlation.ipynb` to analyze the APNIC data against the Freedom of Press Index

## `Look into IE data.ipynb`

For internal purposes only, it won't work without the right credentials, and those can't be shared.

## Generate visualisations

To compare the adoption of resolvers in a visual way, use the notebook `Visualize changes.ipynb`
